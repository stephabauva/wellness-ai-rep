# Claude Code Commands - All Available Options

## ⚡ SHORTEST COMMANDS (Recommended)

### Ultra-Short Single Character
```bash
./c arch-guard      # Shortest possible!
./c workit         
./c clean-code     
./c safe-refactor
```

### Short Command Runner  
```bash
./run-command.sh arch-guard
./run-command.sh workit
```

## 📁 File-Based Commands

### Slash Files
```bash
./_slash_arch-guard
./_slash_workit
./_slash_clean-code
```

### Individual Scripts  
```bash
./slash-commands/arch-guard
./slash-commands/workit
```

### Bin Directory
```bash
./bin/arch-guard
./bin/workit
```

## 🔧 Original System

### Direct Slash Commands
```bash
./run-slash-command.sh "/arch-guard"
./run-slash-command.sh "/workit"
```

### Legacy Runner
```bash
./run-claude-code-command-in-replit.sh arch-guard
node replit-claude-code-commands.js arch-guard
```

## 🚀 Setup Commands

To create all command options:
```bash
./create-slash-aliases.sh          # Original slash system
./setup-direct-slash-commands.sh   # PATH and function setup  
./create-true-slash-commands.sh    # All variants
```

## 📋 Available Commands

| Command | Description |
|---------|------------|
| `arch-guard` | Complete architecture health check |
| `workit` | Production development mode |
| `clean-code` | Code quality validation |
| `safe-refactor` | Refactoring guidance |
| `chew` | Deep analysis mode |
| `ultra-think` | Maximum analysis mode |
| `zapper` | Quick problem resolution |
| `mobile-ux` | Mobile development focus |

## 🎯 Recommendation

For daily use, the **ultra-short commands** are best:
```bash
./c arch-guard
./c workit
./c clean-code
```

These give you Claude Code functionality with minimal typing in Replit!
